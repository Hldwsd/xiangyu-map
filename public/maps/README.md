# 底图数据说明（public/maps/china.json）

ECharts 从 5.0 起不再内置中国地图数据（见 [官方 FAQ](https://echarts.apache.org/zh/faq.html)），
所以底图由本项目自己提供，放在 `public/maps/china.json`，运行时按需下载，不打进 JS bundle。

## 来源与生成方式

| 项           | 值                                                                                   |
| ------------ | ------------------------------------------------------------------------------------ |
| 来源         | 阿里云 DataV.GeoAtlas `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` |
| 正式获取方式 | `pnpm data:china-map`（`scripts/fetch-china-map.mjs`）                               |
| 要素数       | 35（34 个省级行政区 + 南海诸岛）                                                     |
| 体积         | 原始 568.9 KB / gzip 192.8 KB（预算 250 KB）                                         |
| sha256       | `206cf7fd5acba4bb08d9586899acc144cea2b29d9e93ff70f93895c5e5ffde77`                   |
| 抓取时间     | 2026-11-18                                                                           |

要更新底图就重跑 `pnpm data:china-map`，它会把上面的体积与 sha256 重新打印出来；
提交时请同步更新本文件的表格。

## ⚠️ 上线前必须处理（合规）

这是**内部演示用**的示意底图，不是可直接公开的互联网地图：

1. 公开登载地图需要经过地图审核并标注**审图号**（《地图管理条例》、自然资源部与工信部相关规定）。
   M0 阶段先跑通渲染，**公开上线前必须换成有审图号的权威底图服务**，或完成送审。
2. 底图为示意轮廓，边界以官方发布为准；不得作为行政边界、领土主张的依据。
3. DataV.GeoAtlas 数据的使用条款请以阿里云官方说明为准；若上线，需确认商用授权范围。

相关依据：自然资源部《地图管理条例》宣传页
<https://f.mnr.gov.cn/202105/t20210510_2631406.html>；新华/光明网报道
<https://m.gmw.cn/2024-05/13/content_1303736179.htm>。

## 与项目坐标的关系

`src/data/sites.ts` 里的坐标统一按 GCJ-02 记录。底图轮廓与坐标的坐标系一致性，
在换成权威底图时需要一并核对（不同来源的偏移会造成地标与地形错位）。
