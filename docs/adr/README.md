# 架构决策记录（ADR）

记录"为什么这样选"，而不是"选了什么"。每个决策一个文件，编号递增，一旦被取代不删除，改状态并在新 ADR 里说明取代关系。

## 何时写

- 引入/移除关键技术依赖（框架、图表库、状态库、构建工具）；
- 影响多人协作的约定（目录结构、数据契约、路由形态）；
- 有明显替代方案、且选错的代价很高的决定。

## 格式

```markdown
# NNNN. 标题

- 状态：提议 / 已接受 / 已弃用（被 NNNN 取代）
- 日期：YYYY-MM-DD
- 决策人：

## 背景

## 决策

## 理由

## 后果

## 备选方案
```
