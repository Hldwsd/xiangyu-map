# 0021. 首页背景：纸纹 + 程序化水墨远山

- 状态：已接受
- 日期：2026-11-23
- 决策人：项目所有者选定「这一版可以，直接提交」；A（Hldwsd）实现

## 背景

首页只剩一层平纸：书法背景在 #186 按反馈移除，动态水墨宏村在 [0007](0007-ink-paper-home.md#L207-L216) 被否决，理由写得很清楚——「地图占满整屏、省域是实底，动态场景只能从四周露出一窄条；为了不抢信息又把墨色压得很淡，最终看着像糊了一层灰」。

但纯纸也被反馈「空」：地图是一块暖米色，页面是另一块暖米色，四周没有材质，页面像没画完。于是需求变成：**给地图一个背景，但不能是另一张画。**

## 决策

1. **背景分两层，各管一件事**：
   - `body` 上叠一层**纸纹**（内联 SVG `feTurbulence` 噪声，180px 平铺，`multiply`，亮度压在 93%–100%）。0 请求、可平铺、不随视口拉伸，解决「纸是一块纯色」。
   - `body::before` 放一张**水墨横披**（`src/assets/bg-ink.svg`），`opacity: .62` + `multiply` 压进纸里，解决「四周太空」。
2. **横披是程序化生成的静态 SVG**，不是照片/扫描件：`scripts/make-bg-ink.mjs`（`pnpm data:bg-ink`）用固定种子生成 1600×900 的山脊、皴笔、松、雾带、淡日与归鸟；墨色取自现有 token 的墨色系。
3. **强度是一个旋钮**：`0.35` 接近水印、`0.62` 为默认、`0.85` 是上限（再高开始和地图抢）。窄屏同款，不做断点分支。
4. `#app` 抬到 `z-index: 1`，保证远山永远在内容与浮层之下；素材走 CSS 相对路径，Vite 按部署基地址改名。

## 理由

- **背景的任务是托住地图，不是自己表演**：地图全屏铺满，背景真正露出来的只有四周和面板之后约 15–20%。书法版与动态水墨版都是在这个前提下失败的，问题不在画面本身，而在「具象画面被裁成一条缝」。
- **要的是材质，不是叙事**：纸纹给「纸」，淡墨山给「一点山水」，两者都不需要看懂，也就不会和地图的项目点抢注意力。
- **程序化而不是找图**：墨色、层数、位置能跟着纸色与版式调；固定种子可复现；没有照片/扫描件的授权问题；体积 36.8KB（gzip 7.6KB），比书法扫描件的 280KB 小一个量级。
- **不新增依赖、不改地图**：ECharts 配置、数据、配色一行未动，首屏 JS 仍是 274.35KB gzip。

## 后果

- 新增静态资源 `src/assets/bg-ink.svg`（36.8KB / gzip 7.6KB），构建时带哈希；`main.css` 增加约 30 行；`#app` 建立自己的层叠上下文。
- **质量取舍**：程序化山形偏「雾」——脊线细、填充淡，远看像烟而不是写出来的山。想更像手绘，下一步是加浓脊线 / 换黄山式石峰，或直接换一张手绘稿。
- 窄屏 `cover` 会裁掉右上角的淡日，只留底部一条山影；这是有意的（窄屏没有留白可放整幅构图）。
- 回退成本很低：删 `bg-ink.svg` 与 `main.css` 两处（`body` 背景、`body::before`），项目即回到 #186 之后的纯纸。

## 备选方案

- **纯纸（只加纸纹）**：最保守，也最不容易错；但反馈已经说「空」，等于不解决。
- **书法背景 / 动态水墨**：已被 0007 与 #186 否决，不重复第三次。
- **邻省淡底图**：地图感最好的一招，但要多约 100KB gzip、牵出审图合规，而且会把「一张纸」变成「区域图」；值得单独立项，不是本次背景的事。
- **经纬网格 / 图廓版记**：网格像坐标纸，和纸墨气质冲突；图廓版记是改版式，留待版式评审。
