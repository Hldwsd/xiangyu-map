# 0007. 视觉语言修订：纸本墨线（S1）+ 首页版头

- 状态：已接受
- 日期：2026-11-20
- 决策人：项目所有者选定 S1 方向；A（Hldwsd）实现

## 背景

0004 定的是「黑白 / 现代简约」：纯白纸、无衬线、单色圆钉、形状编码。它解决了「样式没有决策」的问题，也把分类从颜色编码里解放出来。但上线前的实际截图暴露出三件事：

1. 纯白底让地图看起来像一张没上墨的底图，省域轮廓和纸面糊在一起；
2. 六类图标是「方框 + 横平竖直」的墨模，27px 下细节互相吃掉；
3. 首页只有搜索条与浮卡，品牌、图例、索引都藏在抽屉里，1440 宽下两侧留白是空的。

经过四轮样张（纸本、图标 A–E、封面 A/B、S1 重心校正），所有者选定 **S1 圆线**：无外框、曲线、每类 3–4 笔，古镇与自然按视觉重心居中，演艺用鼓。视觉基调定为「纸本墨线」：米白纸、墨线、宋体标题、金色只做提亮。

## 决策

1. **视觉语言改为纸本墨线**：`--paper #f4eee2`、`--ink #1c1a17`、`--seal #b08a4a`；标题与地名用系统宋体（`--font-serif`），正文仍用系统黑体；不再引入 webfont。
2. **S1 圆线图标**：六类改为古镇（弧顶拱门）、乡村（稻穗）、非遗（折扇）、红色（飘旗）、自然（双弧山脊）、演艺（鼓）；无外框、曲线、3–4 笔；地图钉为纸白圆钉 + 墨线，选中态墨底纸线 + 金色虚线环。
3. **首页版式**：≥1200px 增加左侧版头（品牌、搜索、图例兼筛选、本期精选、主题路线、版记）与右侧栏（选中卡片、城市索引、关于）；<1200px 沿用顶部搜索栏与浮卡。地图仍全屏铺满。
4. **首屏默认选中徽州古城**（仅桌面）：给「选中态」一个可看见的样子；窄屏不自动弹卡，避免挡地图。
5. **地图性能与可读性**：地标 34px、选中 46px；聚合改为纸色圆盘 + 墨圈 + 墨数字，不再用黑底白字压过地标；选中项若被并进簇，先从簇里拆出来单独绘制并最后入列，保证一定可见。
6. **详情页继承 token**：标题宋体、纸底、章节线；占位图改为纸本墨线山形。

## 理由

- **纸比纯白更像「一张地图」**：米白纸与墨线、青灰水系形成纸墨关系，省域轮廓不需要靠粗边框就能读出来。
- **S1 比方框墨模更适合 27px**：无外框减少一层噪声，曲线与 3–4 笔在小尺寸仍能辨认；古镇/自然按重心而不是包围盒居中，视觉上才真的「在中间」。
- **版头把产品从「工具」拉回「文旅读物」**：品牌、图例、精选、索引都在首屏，用户不需要先点开菜单才知道这是什么。
- **选中项拆簇是交互正确性**：卡片已经显示徽州古城，地图上却只剩一个「3」的簇，等于告诉用户「你选的东西不在地图上」。
- **金色面积仍低**：只用于选中环/标签、路线和版记细线；不承载分类，不替代文字。

## 后果

- **0004 的颜色与字体条款部分被取代**：单色纪律保留，但不再是纯白；标题改用宋体；`--seal` 是新增的唯一强调色。形状编码、token 层、无组件库仍有效。
- **0006 的「全屏地图 + 顶部浮层」在 ≥1200px 被补充**：地图仍全屏、仍浮层，但左侧多了版头；顶部搜索只在 <1200px 使用。
- **新组件**：`HomeRail`、`CityIndex`；`HomeView` 在桌面/窄屏渲染两套浮层。
- **测试**：图标测试改为纸白/墨色断言；新增「选中项在簇里被拆出」用例。
- **已知取舍**：左侧图例与城市索引承担筛选，顶部筛选浮层在桌面变成次要入口；城市索引在 805px 高的屏幕上需要滚动才能看到「关于」。
- **未做**：真实照片、主题路线的可点击实现、移动端新版版式；这些留给后续 PR。

## 备选方案

- **保留 0004 的白底单色**：改动最小，但省域轮廓与图标小尺寸问题都在，等于不解决。
- **用 S2 实心墨团**：27px 更稳，但大尺寸偏「App 图标」，与纸本样张的线刻气质不一致。
- **首页继续只有顶部搜索条**：地图更满，但品牌、图例、索引继续藏在抽屉里。
- **选中项仍并入簇**：实现简单，但会出现「卡片有、图上无」的断层。

## 补充（2026-11-20，落地后评审）

看真实页面后补了三处小修订，不改版式结构：

1. **图例按钮补 ria-pressed**：原来只用 .lrow--on 表达当前筛选，读屏点完听不出状态。
2. **桌面端降噪**：版头图例已承担分类筛选，右上「筛选」降为细线按钮（城市筛选仍只在浮层里，所以没有删除）；底栏不再重复「安徽省 · 16 个地级市」，只保留「拖动探索 · 滚轮缩放」并靠右。
3. **城市索引字号** 8/7.5px → 10/9.5px：纸底上 8px 太吃力；代价是索引变高，「关于」需要滚动到面板底部（原 ADR 已记录该取舍）。

另：详情页封面本来就有 max-height: 380px + spect-ratio: 16/9，不需要再压。

## 补充（2026-11-20，第二轮反馈）

1. **删除「主题路线」栏目**：三条路线始终是「规划中」的静态占位，不能点也不承载信息，
   留着反而像坏掉的功能；模板 / 数据 / 样式一并删除。
2. **桌面整体放大**：html 基准 16 → 17px；版头标题 27 → 30、栏目标签 8.5 → 10.5（500 字重）、
   图例行 11 → 13、城市索引 11px、地图市名 10 → 11；版头栏 272 → 300、右侧栏 284 → 320。
   理由是 1440 宽下正文只有 8–11px，读起来像缩放 80% 的页面。
3. **右侧拆成两张独立的卡**：城市索引不再是长卡片的下半截（独立底色/描边/阴影 + 16px 间距）；
   侧栏隐藏滚动条（scrollbar-width: none，超高仍可滚但不出现灰杠）。
   为在 845 高度不溢出：封面 16:8.4 → 16:6.6、城市索引三列、按钮与间距收紧。
   副作用：封面可视区域变矮；若以后接真实照片，需要重新平衡封面与索引的比例。
4. **缩放条右移 340 → 372px**：右侧栏加宽后原位置会压到卡片左边缘。

## 补充（2026-11-20，第三轮反馈）

1. **整页自适应缩放**：html 基准改 clamp(17px, 0.45vw + 10.5px, 21px)，矮屏（<820 高）再降一档；
   版头 / 侧栏 / 城市索引 / 动作区的字号与宽度改用 rem，大屏上一起放大。
   取舍：rem 体系下地图内的标签字号仍由 ECharts 控制（已单独从 10 提到 12）。
2. **城市索引钉右下**：margin-top: auto + 侧栏固定高度；矮屏（<760 高）索引改四列、封面压扁，
   保证 1284×685 这种尺寸也不溢出。
3. **不再半透明**：版头/索引/按钮/提示条全部改 --surface 实底；版头从「浮在地图上的文字」
   改成一张纸片（描边 + 投影 + 内边距），内部区分线改用更深的 --rule。
4. **缩放条贴最右**：
   ight: 16px，右侧栏左移到
   ight: 4rem 让位（实测间隔 15px）。
5. **地标线宽回到 S1 样张**：GLYPH_STROKE 5.2 → 4.2；非遗折扇中骨收到扇面弧顶（y 12 → 15.9），
   不再出头。之前偏粗，六类在小尺寸下分辨率不够。

## 补充（2026-11-20，详情页收口）

详情页也按同一套「自适应 + 纸片」收了一遍：

- 栏宽 820px 固定 → 56rem（随 html 基准缩放），内边距 clamp
- 头部与四个小节各自成卡（surface 实底 + 描边 + 投影），去掉旧的「一条分隔线」写法
- 上下一条改实底（原 88% 半透明）；封面限高 min(46vh, 30rem)
- ≤720px：实用信息与上下一条都转单列

## 补充（2026-11-20，地标线宽再收）

- GLYPH_SCALE 0.6 → **0.68**（图形占内径约 2/3）、GLYPH_STROKE 4.2 → **3.3**（等效 2.24 单位，34px 钉上约 1.6px）
- 圆钉 34 → **36px**（选中 46 → 48px），聚合阈值 34 → 36
- 原因：线宽接近图形尺寸时，鼓的「桶身 + 两根槌」与折扇的三根扇骨会在小尺寸糊成一团；
  按样张比例把线收细、图形放大后，两类都能认出来

## 补充（2026-11-20，区划以官方标准图为准）

依据安徽省自然资源厅《安徽省示意图（一）》（审图号 **皖S(2025)71号**）：
标准图只划分 **16 个地级市**，没有县区界。据此调整：

- **区县界默认关闭**：首屏不再请求 104 个县级面（省 660KB），地图只有市界 / 水域 / 河道
- 菜单抽屉加「地图图层 → 显示区县界」开关（默认关、记 localStorage、可按需切回）
- 「关于」与 public/maps/README.md 记录标准图来源与审图号

理由：与标准图一致，同时避免「铜陵市郊区」这类真实但易被误读为自造的名称。

## 补充（2026-11-20，宽窄屏融合）

原来宽屏（≥1200）隐藏顶栏、只靠版头；窄屏隐藏版头与城市索引、只靠顶栏，两套布局各缺一半。
现在合成一套：

1. **顶栏常驻**：菜单 / 搜索 / 筛选（宽屏再加一个「列表」，带结果数）。版头与右侧栏整体下移
   到顶栏之下，宽屏右上重复的「列表 / 筛选」删除。
2. **窄屏侧边抽屉**：宽屏左侧的分类图例、右侧的城市索引，在 <1200 变成左右竖排标签
   （32% 高度，避开右侧缩放条）抽出抽屉；两处共用 CategoryLegend.vue / CityIndex.vue。
3. 新增 EdgeDrawer.vue（左/右滑出、焦点锁、Esc 关闭）。

取舍：顶栏常驻后，宽屏地图顶部少了 74px 可用高度；换来两套断点只维护一份入口。
