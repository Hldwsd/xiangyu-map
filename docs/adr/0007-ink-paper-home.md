# 0007. 视觉语言修订：纸本墨线（S1）+ 首页版头

- 状态：已接受
- 日期：2026-11-20
- 决策人：项目所有者选定 S1 方向；A（Hldwsd）实现

## 背景

0004 定的是「黑白 / 现代简约」：纯白纸、无衬线、单色圆钉、形状编码。它解决了「样式没有决策」的问题，也把分类从颜色编码里解放出来。但上线前的实际截图暴露出三件事：

1. 纯白底让地图看起来像一张没上墨的底图，省域轮廓和纸面糊在一起；
2. 六类图标是「方框 + 横平竖直」的墨模，27px 下细节互相吃掉；
3. 首页只有搜索条与浮卡，品牌、图例、索引都藏在抽屉里，1440 宽下两侧留白是空的。

经过四轮样张（纸本、图标 A–E、封面 A/B、S1 重心校正），所有者选定 **S1 圆线**：无外框、曲线、每类 3–4 笔，古镇与自然按视觉重心居中，演艺用鼓。视觉基调定为「纸本墨线」：米白纸、墨线、宋体标题、金色只做提亮。

## 决策

1. **视觉语言改为纸本墨线**：`--paper #f4eee2`、`--ink #1c1a17`、`--seal #b08a4a`；标题与地名用系统宋体（`--font-serif`），正文仍用系统黑体；不再引入 webfont。
2. **S1 圆线图标**：六类改为古镇（弧顶拱门）、乡村（稻穗）、非遗（折扇）、红色（飘旗）、自然（双弧山脊）、演艺（鼓）；无外框、曲线、3–4 笔；地图钉为纸白圆钉 + 墨线，选中态墨底纸线 + 金色虚线环。
3. **首页版式**：≥1200px 增加左侧版头（品牌、搜索、图例兼筛选、本期精选、主题路线、版记）与右侧栏（选中卡片、城市索引、关于）；<1200px 沿用顶部搜索栏与浮卡。地图仍全屏铺满。
4. **首屏默认选中徽州古城**（仅桌面）：给「选中态」一个可看见的样子；窄屏不自动弹卡，避免挡地图。
5. **地图性能与可读性**：地标 34px、选中 46px；聚合改为纸色圆盘 + 墨圈 + 墨数字，不再用黑底白字压过地标；选中项若被并进簇，先从簇里拆出来单独绘制并最后入列，保证一定可见。
6. **详情页继承 token**：标题宋体、纸底、章节线；占位图改为纸本墨线山形。

## 理由

- **纸比纯白更像「一张地图」**：米白纸与墨线、青灰水系形成纸墨关系，省域轮廓不需要靠粗边框就能读出来。
- **S1 比方框墨模更适合 27px**：无外框减少一层噪声，曲线与 3–4 笔在小尺寸仍能辨认；古镇/自然按重心而不是包围盒居中，视觉上才真的「在中间」。
- **版头把产品从「工具」拉回「文旅读物」**：品牌、图例、精选、索引都在首屏，用户不需要先点开菜单才知道这是什么。
- **选中项拆簇是交互正确性**：卡片已经显示徽州古城，地图上却只剩一个「3」的簇，等于告诉用户「你选的东西不在地图上」。
- **金色面积仍低**：只用于选中环/标签、路线和版记细线；不承载分类，不替代文字。

## 后果

- **0004 的颜色与字体条款部分被取代**：单色纪律保留，但不再是纯白；标题改用宋体；`--seal` 是新增的唯一强调色。形状编码、token 层、无组件库仍有效。
- **0006 的「全屏地图 + 顶部浮层」在 ≥1200px 被补充**：地图仍全屏、仍浮层，但左侧多了版头；顶部搜索只在 <1200px 使用。
- **新组件**：`HomeRail`、`CityIndex`；`HomeView` 在桌面/窄屏渲染两套浮层。
- **测试**：图标测试改为纸白/墨色断言；新增「选中项在簇里被拆出」用例。
- **已知取舍**：左侧图例与城市索引承担筛选，顶部筛选浮层在桌面变成次要入口；城市索引在 805px 高的屏幕上需要滚动才能看到「关于」。
- **未做**：真实照片、主题路线的可点击实现、移动端新版版式；这些留给后续 PR。

## 备选方案

- **保留 0004 的白底单色**：改动最小，但省域轮廓与图标小尺寸问题都在，等于不解决。
- **用 S2 实心墨团**：27px 更稳，但大尺寸偏「App 图标」，与纸本样张的线刻气质不一致。
- **首页继续只有顶部搜索条**：地图更满，但品牌、图例、索引继续藏在抽屉里。
- **选中项仍并入簇**：实现简单，但会出现「卡片有、图上无」的断层。

## 补充（2026-11-20，动态水墨宏村背景）

默认背景换成 **Canvas 程序化实时渲染的水墨宏村**（src/components/scene/），静态纸本（邓石如书法）
作为可切换的第二模式，开关在「菜单 → 地图图层」，记 localStorage。

- **场景**：宣纸 + 三层远山（确定性山脊 + 皴笔 + 层间雾）+ 徽派屋舍（白墙黛瓦、阶梯马头墙）+
  石拱桥 + 树 + 芦苇；动态层是南湖倒影（切片翻折 + 摆动）、水波、漂移雾、落墨滴溅、飞鸟。
- **无缝循环**：36 秒一个周期，周期项全部是整数倍正弦；滴溅用半开区间相位，起止都落在
  [0,1) 内，首尾不会出现半截动画（ink-scene.spec.ts 锁住）。
- **性能**：静态层离屏缓存、dpr 上限 1.5、页面隐藏暂停、prefers-reduced-motion 只画一帧。
- **取舍**：为了不压过地图，整体墨色很淡（屋舍线 0.5、水面 0.05），且叠了一层薄纸遮罩；
  如果想要更「满」的画面，调 drawVeil 与各处 alpha 即可。

## 补充（2026-11-20，水墨背景写实化 v3）

按「更写实」重写渲染器（ink-hongcun-scene.ts），从「线条拼贴」转向水墨画的画法：

- **空气透视**：远山 blur 8px / 中景 4px / 近景 1.5px；屋舍整体 0.7px，越远越糊越淡。
- **积墨**：每层山 = 上浓下淡渐变 + 150–230 笔两头淡的湿笔皴 + 山脚墨晕，整层再模糊；山脚夹雾。
- **留白**：屋舍靠纸白与窗洞重墨反衬，不描边；墙根压渐隐重墨让整排落地。
- **水**：倒影 2px 切片逐行摆动 + 水色渐变；水波改湿笔短划；滴溅是三层墨晕 + 飞溅 + 双圈涟漪。
- **纸纹**：整屏 multiply 噪点纸纹 + 极淡暗角。
- 场景占比加大，几乎去掉遮罩。

取舍：地图省域仍是实底，所以画作主要在地图四周与水面区域露出；若要让水墨「透进」省域，
需要把省域填充改成半透明（会影响地图标签对比度），这条需要单独确认。

## 补充（2026-11-21，撤掉动态水墨背景）

实测效果不达预期：地图占满整屏、省域是实底，动态场景只能从四周露出一窄条；为了不抢信息又把墨色压得很淡，
最终看着像「糊了一层灰」。与其留一个不理想的开关，不如删掉——背景回到静态纸本（邓石如书法）。

- 删除 components/scene/（InkHongcun.vue、ink-hongcun-scene.ts）
- 删除 composables/use-background-preference.ts 与 ink-scene.spec.ts
- App.vue / MenuDrawer.vue 去掉挂载、开关与 has-ink-bg 相关样式
- 结论：**画作要好看，需要它自己是主体**；作为全屏地图的底纹，动态渲染的收益不抵干扰。
  如果以后还想要动态背景，更合适的方向是「进入首页前/详情页顶部的一段场景」，而不是铺满地图背后。

## 补充（2026-11-21）：图层默认值调整

线上反馈后调整两个开关的默认值，理由都来自实际使用：

- **区县界改为默认开启**：42 条项目里有不少密集分布在同一条区县（如徽州古城/西递/宏村都在黟县—歙县一带），
  只看 16 个市界定位太粗。代价是首屏多请求一次 `anhui-districts.json`（104 个面）。
- **合并重叠标签改为默认关闭**：数字簇会把「想点的那一个」藏起来。默认逐个绘制后每个项目都点得中；
  需要清爽视野时可在菜单里打开。

两项都记 localStorage（`xy-show-districts` / `xy-merge-markers`），用户改过之后以本地为准。
