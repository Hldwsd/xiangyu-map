# 0008. 版头品牌区：竖排题字 + 朱砂落款印

- 状态：已接受
- 日期：2026-11-21
- 决策人：项目所有者在四方案样张对比中选定方案 D；A（Hldwsd）实现

## 背景

纸本墨线（0007）落地、地图视觉层级（#78）补齐后，版头成了最后一处「文档感」：
「乡遇安徽」横排 1.8rem 宋体 + 2.2rem 墨底金印，第一眼是界面而不是作品。
四方案静态样张（[docs/adr/mockups/rail.html](mockups/rail.html)，纯静态页，随本 ADR 入库）对比：

| 方案 | 内容                      | 结论                   |
| ---- | ------------------------- | ---------------------- |
| A    | 现状基线                  | 文档感，作为对照       |
| B    | 竖排大字（金印落款）      | 气质到位，落款印偏弱   |
| C    | 横排不变 + 朱砂印         | 改动最小、收益立竿见影 |
| D    | 竖排大字 + 朱砂印（组合） | 记忆点最强，被选定     |

## 决策

1. **主标题竖排**：`writing-mode: vertical-rl`、2.4rem 宋体、字距 0.22em；读序从右起，
   副题「在地图上，遇见一个文旅项目」竖排细字列在其左。
2. **落款印紧随标题下方**——传统题字「落款印」的位置，不再横排并置在标题右侧。
3. **新增 `--seal-red: #9e2a22`（朱砂印泥色）**：印改为朱砂底、纸白字；
   这是全页唯一的高饱和色。
4. **「十六市 · 三十处」文案舍弃**：与版头底部 meta「安徽省 · 16 个地级市」重复，
   且数据加到 36 条时这种写死数字必然过期。

## 理由

- **竖排是中文平面设计里最独特的资源**：四个大字竖排，任何语言的用户都能一眼认出
  「这是中文语境的作品」，辨识度远高于横排加字号。
- **「印即朱红」是文化语义，不是配色偏好**：中国书画的落款印传统上就是朱砂，
  朱印出现在纸墨画面上是「完整」，不是「冲突」。
- **全页恰好缺一个视觉锚点**：纸墨语言全是中低明度， choropleth 与金环都是低饱和；
  一枚 2.6rem 的朱砂印面积极小（<0.5% 版面），却让视线有了第一落点。

## 后果

- **0007 的「金色只做提亮」单色纪律出现唯一例外**：朱砂不承载分类、不用于选中态，
  只出现在版头落款印一处。将来若有人想给别的元素用朱砂，先来这里改条款，而不是直接加色。
- **版头加高约 1rem**：矮屏（<760px 高）品牌区收一档（8rem / 2rem 字号），
  与既有的「矮屏版头要滚动」取舍（0007 第二轮反馈）叠加，挤出量可控。
- **纯 CSS 实现**（writing-mode + 一个变量），无新依赖、无 bundle 增量；
  印从墨底金字改为朱砂底纸白字，对比度 5.9:1（AA）。
- 无楷体/宋体环境竖排仍生效（writing-mode 是 CSS 属性，不依赖字体），字体回退栈不变。

## 备选方案

- **方案 B（竖排 + 金印）**：不动单色纪律，但落款印与纸底对比弱（金对纸白 2.9:1），
  锚点作用打折。
- **方案 C（横排 + 朱砂印）**：最省事，但「文档感」的根因（横排小标题）没解决。
- **维持 A**：等真实照片上线后再看——已被否，版头是第一落点，照片救不了它。
