# 0009. 悬停不重绘市域：把「不被盖住」交给绘制顺序，而不是调 emphasis 颜色

- 状态：已接受
- 日期：2026-11-21
- 决策人：A（Hldwsd）实现；记录直接来自三轮线上反馈与像素采样

## 背景

地图把 16 个市、水域、区县合并成一张 geo，hover 用 `geo.emphasis` 做反馈。用户连续报了三次：

1. 悬停市域时阴影把河流盖住
2. 悬停市域时湖面被盖成纸色
3. 按「填透明」修后，悬停的城市直接变成洞、露出页面书法背景；长江淮河也一起消失

## 试过、都不成立的三条路

| 方案                                              | 结果                                                                                      |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| emphasis 填不透明档位色                           | 悬停区域被重绘在所有 region 之上，湖面/河流被盖                                           |
| emphasis 填 `transparent`                         | 区域变成 `alpha=0` 的洞（页面背景透出），水系随之消失                                     |
| 湖面拆成第二个 geo（共用 boundingCoords，`z: 6`） | 不盖色了，但原生 roam 只改主 geo，滚轮/双指缩放时两层永远差一帧；`z` 高于地标时还压住地标 |
| 湖面拆成 `map` 系列 + `geoIndex: 0`               | 该构建下 `map` 系列注册不上（`getProgressive` 报错），页面直接进错误态                    |
| custom 系列画湖面                                 | 同上，custom 系列在该构建里也抛 `getProgressive`                                          |

## 决策

**关掉 geo 的区域重绘**：`emphasis: { disabled: true }`。

- 悬停反馈改由既有 `tooltip: { trigger: 'item' }` 承担（实测悬停九华山会弹出分类 + 摘要）
- 湖面、水域回到主 geo 的 region，按正常绘制顺序画在城市之后，不会被任何 hover 重绘覆盖
- 单 geo → 缩放天然同步，不存在两层对不齐
- 地标 `z: 3` 在 geo 之上，没有任何图层压住它

## 代价

悬停时**不再有市域描边加深与市名加粗**。这是明确取舍：区域重绘与「水系不被覆盖」在 ECharts 的 geo 里不可兼得；tooltip 仍然给到即时反馈。

## 验证（可作为回归基线）

- 巢湖像素：悬停前 / 悬停城市 都是 `rgb(220,228,225)`
- 城市像素悬停时 `alpha=255`（无洞）
- 长江/淮河河线像素：5916 → 5916
- 悬停九华山：tooltip 正常
- 116 用例、五闸门全绿、gzip 252.46 kB

若以后要恢复 hover 高亮，正确方向是**给市域单独一个高亮层**（例如 hover 时用 `lines` 系列沿边界描边，而不是让 geo 重绘区域），不要再直接改 `geo.emphasis`。
