# 0014. 分享图：数据显式 `shareImage` + 详情页分享弹层

- 状态：已接受
- 日期：2026-11-23
- 决策人：B 记录，A 评审

## 背景

头部 12 个项目此前已有 1200×630 分享图，放在 `public/og/sites/<id>.jpg`，但接入方式是隐式的：

- `scripts/prerender-sites.mjs` 靠 `existsSync(dist/og/sites/<id>.jpg)` 决定用专属图还是默认图；
- 数据层、校验和测试都看不到这张图；
- 详情页没有分享入口，用户只能复制地址栏；分享出去是哪张卡片不可见；
- 58 个项目始终共用 `og-cover.jpg`。

隐式文件约定在只有 12 张时还能靠记忆维护，但一旦增删图片，数据和构建产物很容易漂移。

## 决策

1. **数据显式声明**：`Site` 增加可选 `shareImage`，值为 `/og/sites/<id>.jpg`；
   校验要求文件名与 `id` 一致；未填时回退 `/og-cover.jpg`。
2. **预渲染以数据为准**：`prerender` 使用 `site.shareImage ?? '/og-cover.jpg'`，
   并在文件不存在时直接失败，不再静默回退。
3. **补全 OG**：`og:image:type`、`og:image:alt`、`twitter:image:alt`。
4. **详情页分享弹层**：展示当前卡片，支持复制链接、保存图片、系统分享
   （`navigator.share`）；不引入第三方分享 SDK，不加追踪参数。
5. **覆盖范围先保持 12 个头部项目**；其余 58 个继续用默认图。全量生成另开 PR，
   按 1200×630、质量 80 左右评估仓库体积后再做。

## 理由

- 显式字段让“这张图属于哪个项目”在数据、校验、测试、构建四处一致；
- 弹层让用户看到分享出去的样子，复制链接/系统分享是低成本的实用入口；
- 12 张精选图已经过视觉评审，先不把 58 张未评审的图塞进仓库；
- 社交平台只认静态 URL，运行时 Canvas 生成不能替代 OG 图，因此继续用构建产物。

## 代价

- 契约变更：`src/types/site.ts` 新增字段，需要双方在 PR 确认；
- 12 条数据要维护 `shareImage`，图片改名时要同步数据；
- 详情页多一个懒加载的弹层组件与约 3 KB CSS/JS（入口 JS 仍在 300 KB 内）；
- 58 个项目仍共用默认图，分享卡片没有项目名；全量生成是后续独立决策。

## 备选方案

| 方案                             | 不选的原因                                                     |
| -------------------------------- | -------------------------------------------------------------- |
| 继续用 `existsSync` 隐式约定     | 数据和测试看不到，文件名漂移只能到构建时发现                   |
| 运行 `import.meta.glob` 推断图片 | `public/` 不进 Vite 模块图，且构建后路径需要稳定；不如显式字段 |
| 运行时 Canvas 生成分享图         | 社交平台抓不到，且每个用户生成结果不可控                       |
| 一次性给 70 个全量生成           | 图片体积、逐张视觉评审成本高；先保留 12 张精选                 |

## 更新（2026-11-23）

v0.2 前把覆盖扩到 **69/70**，随后（2026-11-23）补到 **70/70**（徽菜博物馆换新封面后也生成卡片，不再保留默认图样本）：

- 12 个头部项目保留 `make-og-images.py` 的人工文案；
- 其余 57 个由 `make-og-images-all.py` 用「封面临摹 + 左/底渐变 + 名称/摘要/城市」模板生成；
- 徽菜博物馆故意保留 `og-cover.jpg`，作为 `shareImage` 缺省回退的线上样本（E2E 也依赖它）；
- 新增图片约 **8.4 MB**，`public/og/sites` 总计约 10.5 MB；`prerender` 继续显式校验文件存在；
- 全量生成前已看 69 张缩略图总览；自动卡片不如 12 张人工精选，但标题/摘要可读，满足分享卡最低标准。

## 验证

- `pnpm test:unit --run`：144 用例，新增 shareImage 合法/非法路径用例；
- `pnpm prerender`：70 个详情页；黄山输出 `/og/sites/huangshan-scenic.jpg`，
  徽菜博物馆回退 `/og-cover.jpg`；
- `pnpm test:e2e`：10 passed, 2 skipped；覆盖分享弹层、专属图与默认图；
- `og:image:alt` / `twitter:image:alt` 在预渲染 HTML 中可见；
- 入口 JS 256.53 KB / 300 KB（85%）。
