# 0011. 封面素材来源：百度百科词条主图

- 状态：已接受（所有者指示）
- 日期：2026-11-22
- 决策人：项目所有者；A 执行采集与置入

## 背景

63 条数据长期使用 `placeholder.svg`。先试过 Wikimedia Commons（CC 授权、可追溯），
但所有者审核后认为图片质量不合格，要求改用**百度百科收录的图片**。

## 决策

1. 封面取自各词条 `<meta property="og:image">` 的**原图**（去掉 536px 缩略参数），
   从 `bkimg.cdn.bcebos.com` 下载；
2. 逐条人工审核：所有者替换了不合格的图，并补了 12 张百科没有的词条主图
   （安徽博物院、八公山、司空山、再芬黄梅公馆、云岭、查济、茂林、柳孜、铜陵凤凰山、
   张公山、六尺巷等）；
3. 统一转 WebP、宽 ≤1920、单张 ≤300 KB，放 `public/images/sites/<id>/cover.webp`；
4. 按城市分批置入（16 批），每批一个 PR，完成后数据为 63 条全部有封面。

## 理由

- 「封面要能代表这个项目」优先于「授权链路最干净」——Commons 的图虽然授权清晰，
  但很多是游客随手拍或门楼局部，观感不合格；
- 百科主图是词条运营挑选过的图，命中率明显更高。

## 后果 / 风险

- **版权风险**：百科图片多为用户上传或转自官网，不是可自由分发的授权素材；
  公开商用前需逐张确认权利人或替换为官方授权图。这一点已在 PR 与审核说明里注明；
- 采集依赖浏览器通过百度安全验证；脚本直连会 403，故采用「浏览器过验证 → 逐条取 og:image」；
- 部分条目百科无主图或命中同名异地条目（八公山、铜陵凤凰山、司空山、茂林、柳孜等），
  由所有者手工补图解决。
