# v0.1.0 · 乡遇安徽

第一个比赛交付版：**安徽省地图 + 70 条文旅项目 + 详情页 + 分享卡片 + 品牌页**，同时提供 Windows 与 Android 安装包。

线上：https://hldwsd.github.io/xiangyu-map/

## 本期能力

- **地图**：16 个地级市分区、9 个湖泊与长江/淮河水道、省界光晕、区县界图层；拖动夹取按省域外框。
- **地标**：70 个项目 / 7 类；软碰撞小球，密集处自然挤开，缩放/拖动时跟随地图平移。
- **详情页**：建议停留、最佳季节、交通、适合人群、图集、同城推荐、高德精确 POI 短链；70 个详情页预渲染 title/OG/JSON-LD。
- **分享**：详情页分享弹层（复制链接/保存图片/系统分享）；70/70 项目有独立分享图。
- **品牌页**：`/brand/` 滚动叙事（省界描边、逐字显墨、六处项目 pin、十六城索引、七类风物抽屉）；App 启动先到品牌页，地图是品牌页入口。
- **多端**：Tauri 2 Windows NSIS 安装包、Android arm64 APK；两端共用同一份前端产物与品牌页入口。

## 安装包

| 平台    | 文件                                        | 说明                                                           |

## 已知问题

- **审图号**：底图需替换为经审核数据并申请审图号后才能公开合规上线；
- **图片授权**：封面/画廊/分享图来自公开资料，商用前需逐张确认或替换授权素材（ADR 0011）；
- **内容深度**：20 条 practical 缺 hours/ticket；58 条没有画廊；演艺只有 1 条；详情页“看点/路线/周边”未做；
- **窄屏地标密度**：360dp 高密度区域仍需依赖“合并重叠标签”；
- **签名**：Windows 未签名、Android 为演示证书，仅适合比赛/内部分发。
